Y vamos a hablar sobre los detalles más resaltantes que tiene Jupyter Notebook. Los dos componentes principales de Jupyter Notebook son un conjunto de núcleos o intérprete y el dashboard. Cada núcleo o kernel es un motor de ejecución para un lenguaje en particular. Y este kernel se encarga de procesar las solicitudes o el código que estamos escribiendo en nuestro programa y de devolver las respuestas apropiadas. El kernel por defecto es ypython que es un intérprete de líneas de comandos que permite trabajar con Python. Gracias a los otros kernels que están disponibles, es posible trabajar también con otros lenguajes como por ejemplo C++, R, Julia, Ruby, PHP o Java. Por un lado, el dashboard o el panel de control funciona como una interfaz de administración de cada uno de los kernels. Y por otro, como un centro de control desde donde es posible crear nuevos documentos como lo hemos hecho hace un momento con este Jupyter Notebook o abrir proyectos existentes. Por este motivo decimos que un Jupyter Notebook es agnóstico al lenguaje de programación. En este caso nuestro kernel es Python 3. Y por último, debo decir y resaltar que Jupyter Notebook es un software gratuito, cualquier usuario lo puede usar, vale, tiene una licencia bsd modificada.
