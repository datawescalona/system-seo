Ajax es un conjunto de tecnologías que permiten realizar llamadas a servidores desde los navegadores sin necesidad de refrescar la página web. Antiguamente cada vez que teníamos que volver a cargar contenido será necesario actualizar la página web por completo y cuando nace la tecnología Ajax, pues este problema desaparece y gracias a esta tecnología somos capaces de hacer llamadas asíncronas a un servidor sin necesidad de actualizar la página web. En la diapositiva vemos un ejemplo de este tipo de peticiones en el que vamos a cargar en un elemento de la HTML con el ID demo el contenido existente en un archivo llamado Ajax barrabajainfo.txt. Si analizamos el código de este ejemplo vemos que en el código HTML se genera un botón con una función y que dentro de esta función existe una petición Ajax. En la clave a la derecha tenemos el contenido del archivo y vemos que cuando carga la página web este contenido no existe y únicamente clicando el botón sin necesidad de actualizar la página somos capaces de cargar un contenido externo, un contenido de un archivo de texto en el mismo HTML. Esto es realmente útil ya que podemos cargar contenido no únicamente de archivos.txt sino de otras fuentes de información como por ejemplo XMLs o como por ejemplo una base de datos. Interactuando con botones o desplegables desde un código HTML sin necesidad de refrescar esta página. En la tecnología Ajax se definen varias propiedades que nos permiten controlar un poquito esta conexión externa. Al ser una conexión asíncrona no sabemos cuánto tiempo tarda en responder el servidor y todos estos estados y todas estas propiedades nos permiten saber si la conexión se está desarrollando en ese momento si estamos pendientes de respuesta, si esta conexión ha finalizado y el estado final es un ok o es una página no encontrada etc etc. Son estas cuatro propiedades las que nos ayudan a controlar todos estos estados.
