Hola de nuevo, iniciamos el segundo punto del curso de programación 2 del Master Deseo del Bixello, en el que hablaremos de los riche snippets. Los riche snippets son fragmentos de código HTML que sirven para etiquetar los contenidos de nuestra página web. De esta forma los navegadores entienden mucho mejor el contenido de nuestra página web y muestran mejores resultados a los usuarios. Algunos ejemplos de etiquetado pueden ser los autores, valoraciones, eventos, productos, etc. Normalmente los resultados con riche snippets llaman más la atención al usuario que los resultados que no nos contienen y por lo tanto es más probable que hagan clic en ellos. En la captura de pantalla de la diapositiva vemos el esquema de un producto, el etiquetado de un elemento producto que se puede hacer desde riche snippets y vemos un ejemplo, tienen muchas más etiquetas se le pueden añadir propiedades, se le pueden agregar puntuaciones, audiencias, categorizar, colores, etc. Cada tipo de elemento tiene un esquema particular, por ejemplo una película, tendría autor, tendría género, tendría puntuación, etc. Los riche snippets se basan en un estándar y toda la información la podemos encontrar en esta URL de schema.org. Existen tres formas para realizar este etiquetado de los elementos. La primera de ella consiste en añadir micro datos dentro de las etiquetas HTML, como vemos en este ejemplo. Aquí estamos especificando en el código HTML que estamos usando el esquema Movie y usamos todos los elementos con la etiqueta ItemProp para que Google entienda mejor que lo que tenemos en el contenido de nuestra página es una película. Si nos fijamos estamos especificando el nombre, el director, también añadimos información para que Google entienda que estamos hablando de una persona. De esta persona añadimos también más propiedades como el nombre, la fecha de nacimiento, etc. Este sería un ejemplo de esquema con micro datos en HTML. La segunda forma de incluir esta información, los riche snippets, sería utilizar el estándar rdfa que al final es una extensión que se creó para el lenguaje HTML5, que veíamos anteriormente para HTML y este es para el lenguaje de HTML5. Al final la lógica de funcionamiento es similar, lo único que cambia es la forma de etiquetado, la sintaxis. Y todo esto cuando lo utilicemos, pues tenemos que ir contrastándolo con páginas web oficiales donde podemos consultar el estándar y todos los elementos y etiquetas válidas para el contenido que estemos mostrando. Y la última forma que tenemos para etiqueta riche snippets es usando el estándar JSON-LD. Este estándar es el más recomendado por Google y al final consiste en añadir un objeto, un script JSON con los datos a catalogar como riche snippets. Los objetos JSON son muy comunes y hoy en día todos los lenguajes y plataformas saben trabajar con ellos. Entonces en esta captura de pantalla vemos un ejemplo también del esquema de una película con varias etiquetas de las que se le pueden añadir y etiquetándolas en formato JSON. Cuando implementamos riche snippets al final lo que buscamos es que Google entienda mejor el resultado y Google también a veces muestra el riche snippet en el mismo resultado de búsqueda.
