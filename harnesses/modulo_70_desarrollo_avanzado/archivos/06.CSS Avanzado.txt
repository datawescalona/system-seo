Comunmente, cuando desde las diferentes páginas web se hacen enlaces, por ejemplo a redes sociales, es muy común adjuntar cada logo de cada red social como una imagen independiente y enlazar cada una de ellas. CSS Sprite lo que intenta es mejorar este funcionamiento, porque si al final tenemos cuatro redes sociales y enlazamos cuatro imágenes, pues estamos haciendo que nuestra página web, lance cuatro consultas al servidor, se descargue las cuatro imágenes de forma independiente y bueno, las enlaces y las trabajen. Entonces, con CSS Sprite, que al final es una configuración sobre todo la hoja de estilos de CSS, podemos conseguir que con una única imagen tengamos a nivel visual lo mismo que conseguiríamos con estas cuatro. Y por último vamos a ver las media queries. Las media queries son unas sintaxis específicas de CSS que nos permiten mostrar una página web con estilos diferentes en base a el dispositivo que las está consultando. Aquí tenemos varios ejemplos, podemos basarnos en la anchura, en la anchura máxima del dispositivo, anchura mínima, también en la orientación de la pantalla si consultamos la documentación oficial vemos que podemos definir diferentes estilos en base a estas dos orientaciones. Y bueno si las vemos funcionar pues vemos que por ejemplo en este caso se está cambiando de color, se está aplicando esta media query cuando cambia la orientación de la pantalla y se está poniendo de color azul claro. Y por defecto el color de fondo está definido como green clarito. Hasta este punto se considera que la pantalla es más bien vertical y a partir de que superamos la anchura, bueno a partir de que la anchura supera la altura consideramos que aquí sería completamente cuadrada, misma altura, misma anchura y a partir de aquí ya consideramos que es una página horizontal y esta media query cambiaría el color de fondo a la englú.
