Iniciamos con el primer punto del curso de programación 2 en el que hablaremos de los breadcrumbs. Los breadcrumbs, también llamados migas de pan, son barras de navegación secundarias de las páginas webs. Normalmente se utilizan para mostrar una ruta lógica desde la página principal hasta la posición actual en la que se encuentra el usuario navegando. Son muy importantes para SEO ya que mejoran la usabilidad web del usuario, además de que mejoran el enlazado interno de la página web, ya que conseguimos que todas las páginas webs de nuestro site contengan diferentes enlaces a sus páginas anteriores o incluso a la página principal de la home. Si miramos este ejemplo de código vemos que recordando la estructura de código de HTML, los breadcrumbs se suelen poner en el apartado nav y al final son una lista, una lista como las que trabajamos en el curso de HTML con sus etiquetas ll, sus etiquetas list y dentro de cada li contienen enlaces que son elementos del tipo A a las diferentes páginas que vemos. El ejemplo de breadcrumbs que hay en la diapositiva hace referencia a la página web de Zalando. Si os fijáis aquí cuando nosotros vamos navegando por los diferentes apartados, ahora estamos en sudaderas, ahora cambiamos a sudaderas con cremallera, si cambiamos a chaquetas. Si os fijáis esta barra de navegación va cambiando en base a la página en la que estoy navegando en el momento. Y si analizamos este código pues vemos lo que comentábamos, es una lista, un elemento del tipo weller que contiene diferentes elementos list y dentro de cada li existe un elemento A que es el enlace que al clicarlo nos lleva a la página web del elemento que estemos clicando, en este caso la categoría chaquetas. Si nos fijamos también el último elemento que hace referencia al elemento actual en el que nos posicionamos no contiene ningún enlace porque sería un enlace a esta misma página en la que se está navegando y no tendría sentido. Existen muchas formas de construir estos breadcrumbs, los cms es como WordPress, Joomla u otras herramientas, a veces incorporan plugins que nos construyen toda esta barra de navegación y si no pues siempre se pueden hacer en cada página picando código, ya sea PHP, JavaScript, HTML, podemos crear estas barras de navegación. Además podemos aplicar tanto se monten a través de un plugin o lo estemos desarrollando a nosotros a mano, siempre podremos modificar los estilos mediante la hoja de estilos tss y decidir el color, la posición, el tamaño de letra y todos los elementos y todo lo referente a la visualización de esta barra de navegación. Y bien, con esto finalizamos el primer punto del curso de programación 2 y nos vamos al segundo donde veremos los rich snippets.
