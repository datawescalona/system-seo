Ahora bien ¿Qué es un framework? Si nos teníamos a lo que sería la definición del libro de frameworks, sí podemos ver lo de qué es un conjunto estandarizado de conceptos, prácticas y criterios para enfocar un tipo de problemática particular que sirve para hablar como referencia. Para enfrentar y resolver, no es problema de índoleis y milas. Bien, todo esto está muy bien. Básicamente para que lo entendamos para mí la mejor forma de definirlo sería decir que sería un ecosistema. Básicamente cuando estamos con un framework de algún tipo de lenguaje, lo que estamos es astándonos a un ecosistema, a una forma de hacer las cosas. Que bueno, sí sería lo de conjunto estandarizado de conceptos tal, simplemente para que vosotros lo tengáis en mente, para mí lo que sería esa palabra clave para entender qué consiste esto exactamente es un ecosistema que al final primero digamos que junta ciertos conceptos de ese lenguaje para atajar el tener que hacer una línea de código que sería pues de este tamaño para poder hacer dos líneas, es decir lo que sería como hacer atajos que al final si entendemos lo que es la historia de la programación y nos vamos a lo básico que ahora lo explico más en profundidad. Realmente aquí lo que vamos a ver es que ya se tiene montado una estructura de web para decir dónde está cada componente, dónde está cada cosa y en base a esa estructura es como se hace la web. Eso es lo que consistiría un framework. Para decir otra forma sería como para nosotros un conjunto de códigos ya prehechos en un lenguaje de programación para ahorrar tiempo de trabajo en la creación de una página web. Por ejemplo a la hora de crear un backend o crear un sistema de registro de usuarios pues todas estas cosas ya la tenemos dentro de esa estructura que ya está hecha y luego veremos la diferencia entre un framework y una librería. Lo vamos a ver más en profundidad pero primero quiero que entendáis básicamente lo que es el concepto básico.
