Las cláusulas más importantes que vamos a tener que ver ahora para que podáis construir vuestras propias queries. Primero, muy importante, el orden si importa. En mis ejemplos vais a ver que hay cláusulas donde os digo select from where y otros que vamos a ver después. El orden importa. Es decir que si usáis mi código y ponéis el from primero, vale en plan from base de datos, select, tal, no va a funcionar. El código os va a decir no, no, no puede ejecutar y tal. El orden importa si no no funciona. ¿Por qué importa? Porque básicamente lo que pasa es que el código se leye desde arriba abajo, sistema que lo interpreta. Entonces si no respetamos el orden realmente están intentando ejecutar algo que no tiene sentido.
