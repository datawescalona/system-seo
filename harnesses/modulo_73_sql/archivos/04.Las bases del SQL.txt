Un código SQL siempre contiene tres partes, es el que, de dónde y opcional, lógica. Aquí, por ejemplo, tengo una cuera muy simple, donde yo quiero obtener la suma de impresiones desde México. Entonces aquí le pongo que, suma de impresiones, lo veis aquí en el primer cuadro rojo, de dónde el nombre de mi base de datos, porque podéis tener más de una obviamente, y la condición donde el país es igual a MEX, aquí no pongo México porque con la API de SERS console, cuando estáis la información, cada país se designa por un código ISO, no hay tres letras para designar un país, ESP para España, MX para México, por ejemplo. Y esa es la estructura base de una query, de dónde y la lógica. Ahora vamos a ver más en el dedícado, algunas de esas partes todos preocupéis, pero para que veáis cómo se construye una muy sencilla.
